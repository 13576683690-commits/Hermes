# 自优化规则

## 目标

把反复出现的有效经验变成未来可复用的规则、检查表、模板和提示词。不写流水账。

## 任务完成前全量回读复盘

每次任务完成前，必须重新读取并整理本任务从开始到结束的全部记录。

### 必须整理

1. 用户原始需求和后续补充
2. 本模块负责内容、边界和未处理事项
3. 本次读取的文件、调用的工具、执行的动作和验证结果
4. 本次遇到的问题、阻塞、风险判断和处理方式
5. 本次产生的可复用步骤、检查项、提示词、字段口径、文件路径、回传格式和验收标准

### 处理规则

1. 凡能服务未来同类任务的内容，必须更新到本模块 Agent 文档或允许维护的检查表/模板中
2. 不把一次性流水账、未经核验数据、真实密钥或未脱敏信息写入长期文档
3. 如果本轮没有可沉淀内容，回传中写明：已完成全量回读复盘，本轮无可沉淀 Agent 文档更新项
4. 如果需要修改其他模块文档、AGENTS.md 或共享规则，暂停并提交主控

## 允许范围

- 本模块的 Agent 文档（docs/agents/<module>.md）
- 本模块检查表
- 本模块回传格式
- 本模块命名规范

## 禁止范围

- 不修改 AGENTS.md（主控专属）
- 不修改其他模块的 Agent 文档
- 不修改共享资源、Skills、权限规则或风险门禁
- 不写入密钥、账号、未脱敏数据
- 不把一次性流水账写入长期文档
