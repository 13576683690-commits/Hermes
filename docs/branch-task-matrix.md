# 模块职责矩阵

> 每个分支只对自己的职责负责。跨分支任务必须先回到主线程拆分。不确定归属时先提交主控判断。

| 模块 | 核心职责 | 可直接处理 | 必须提交主控 |
|---|---|---|---|
| 主控 (main) | 总控规则、任务拆分、优先级、跨模块协调 | 全局调度 | — |
| 前端 (frontend) | React 组件开发、UI/UX、构建验证 | 修改 src/ 组件、调整样式 | 改变数据结构、新增依赖 |
| 数据 (data) | data.json 管理、归档追加、数据完整性 | 追加新归档条目 | 修改历史数据、改变 schema |
| 部署 (deploy) | GitHub Actions、Pages 发布、远端状态 | 本地构建验证、推送 main | 修改部署目标、force push |
| 自优化 (self-optimization) | 复盘规则、可复用经验沉淀 | 更新本模块文档 | 修改 AGENTS.md 或共享规则 |

## 规则

- data.json 历史数据不可变，只追加新条目
- 修改 data.json 前必须先备份
- 前端代码改动后必须本地 `npm run build` 验证通过
- 跨模块任务必须先回到主控拆分
- 不确定归属时先提交主控判断
