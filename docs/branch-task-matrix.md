# 模块职责矩阵

| 模块 | 核心职责 | 可直接处理 | 必须提交主控 |
|---|---|---|---|
| App 主组件 | 数据加载、视图路由、布局 | 修改渲染逻辑、调整布局 | 改变数据结构 |
| ArchiveCard | 单条归档卡片展示 | 修改样式、交互 | — |
| StatsGrid | 顶部统计 | 修改样式 | — |
| ViewRouter | 选项卡切换 | 修改样式 | — |
| data.json 数据层 | 唯一数据源 | 追加新归档条目 | 修改历史数据 |
| GitHub Actions 部署 | 自动构建+部署 | 修改工作流配置 | — |

## 规则

- data.json 历史数据不可变，只追加新条目
- 修改 data.json 前必须先备份
- 前端代码改动后必须本地 `npm run build` 验证通过
