# 知识路由表

| 内容类型 | 沉淀通道 | 适用场景 | 示例 |
|---|---|---|---|
| 可复用流程/SOP | Hermes skills | 多次重复的任务模式 | "项目初始化流程" |
| 事实性信息/偏好 | Hermes memory | 跨会话需要记住的事实 | "用户偏好深色系设计" |
| 正式文档/规格 | 仓库 docs/ | 项目交付物 | "部署指南"、"模块职责" |
| 归档数据 | public/data.json | 进化记录（不可变） | Skill/记忆点/进化点/探索节点 |

## data.json 数据追加规则

1. 新归档只追加，不修改历史条目
2. 同一天的多次对话合并为一条归档（同日合并增量原则）
3. 无实质进化不归档（实质进化门槛）
4. 追加前必须有明确的 skill/memory/evolution/node 提炼
